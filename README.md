# Vasilisk Virtual Studio — сайт

Исходник страницы **https://vasiliskstudio.github.io** — студия, где ты сам обучаешь свой ИИ:
текст, картинки, видео, музыка, голос, зрение — на своём маке, на своих данных.

Сама программа:
- [vasilisk-dev](https://github.com/VasiliskStudio/vasilisk-dev) — полная сборка Dev и релизы;
- [vasilisk-x](https://github.com/VasiliskStudio/vasilisk-x) — открытый код, MPL 2.0.

English version: https://vasiliskstudio.github.io/en/

Сторонние части: [three.js](https://threejs.org) (MIT), шрифты Handjet и Jersey 10 (SIL Open Font License 1.1,
тексты лицензий — в `assets/licenses/`).
